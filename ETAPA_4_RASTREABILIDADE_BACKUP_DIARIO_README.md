# ETAPA 4 - Controle físico, rastreabilidade e backup diário

Alterações aplicadas:

1. Backup automático diário ao abrir o app.
2. Controle para ligar/desligar backup diário em Configurações.
3. Registro da última data/hora do backup automático.
4. Botão para testar/forçar backup diário.
5. Campo Localização física no cadastro do item.
6. Campo Foto do item / URL da imagem.
7. Campo Anexos / referências para notas, orçamentos, links e PDFs.
8. QR Code do item apontando para a tela do estoque com o item selecionado.
9. Etiqueta de prateleira com código, nome, local, uso, categoria e mínimo.
10. Filtro de itens sem localização no estoque.
11. Detalhes do item agora mostram localização, foto e anexos.
12. Nova tela Ferramentas no menu lateral.
13. Controle de ferramenta com status: disponível, emprestada, em manutenção, perdida e descartada.
14. Campo responsável pela ferramenta.
15. Registro de movimentação quando ferramenta é atualizada.

Observação: por limitação do navegador, o backup diário roda quando o sistema está aberto/logado. Ele não roda se o navegador/computador estiver fechado.
