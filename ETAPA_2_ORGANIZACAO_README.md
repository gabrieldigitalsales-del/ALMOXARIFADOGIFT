# ETAPA 2 — Organização

Versão focada em organização do sistema após a etapa de segurança.

## O que foi adicionado

1. Nova tela **Organização** no menu lateral.
2. Aba **Duplicidades** para ver códigos, nomes e máquinas parecidas.
3. Aba **Mesclar máquinas** para escolher uma máquina principal e arquivar duplicadas.
4. Ao mesclar máquinas, os vínculos da estrutura são movidos para a máquina principal.
5. Antes da mesclagem é baixado backup automático.
6. Aba **Arquivados** para ver itens e máquinas arquivadas.
7. Opção de restaurar itens arquivados.
8. Opção de restaurar máquinas arquivadas.
9. Aba **Vínculos** para ver linhas de BOM/estrutura quebradas.
10. Botão para arquivar vínculos quebrados sem apagar definitivamente.
11. Registros de movimentação para item arquivado/restaurado, máquina arquivada/restaurada e mesclagem.
12. Máquinas e itens arquivados continuam fora das telas principais, mas recuperáveis.
13. A tela de saúde do banco continua contando arquivados e vínculos quebrados.
14. Rota /organizacao protegida para administrador.
15. Menu com acesso direto à organização.

## Segurança

Nenhuma função nova apaga estoque em massa. As ações usam arquivamento e backup antes de mexer em dados sensíveis.
