# Atalho de notificação para item no estoque

Alteração aplicada:

- Ao clicar em uma notificação de estoque baixo/em falta, o sistema agora vai para:
  /estoque?item=ID_DO_ITEM

Na tela de estoque:
- o item é filtrado automaticamente pelo nome;
- o modal de detalhes do item abre automaticamente;
- o histórico daquele item fica visível direto.
