# Pop-up personalizado, devolver tudo e status por colaborador

Atualizações aplicadas:

1. Pop-up personalizado dentro do sistema
- O aviso de alterações não salvas não usa mais o alerta padrão do navegador.
- Agora aparece uma janela interna no padrão visual do sistema:
  - Continuar editando
  - Sair sem salvar

2. Botão Devolver tudo
- Dentro de Colaboradores > colaborador, cada ferramenta possui:
  - Devolver
  - Devolver tudo
- Devolver tudo já abre a devolução com a quantidade total daquela ferramenta.

3. Status de tempo com a pessoa
- Cada ferramenta mostra há quantos dias está com o colaborador:
  - Com a pessoa desde hoje
  - Com a pessoa há 1 dia
  - Com a pessoa há X dias
