# Ajustes de colaboradores e movimentação

Alterações:

1. No login de funcionário, o campo Reservado foi removido do resumo do item.
   Agora aparecem apenas:
   - Estoque
   - Disponível
   - Unidade

2. Na aba Colaboradores, os cards ficaram mais limpos.
   Cada card mostra apenas resumo:
   - quantidade de itens fora
   - quantidade de tipos de ferramenta
   - última movimentação

3. Ao clicar no card de um colaborador, abre a visão interna da pessoa:
   - ferramentas que estão atualmente com ela
   - quantidade de cada ferramenta
   - última movimentação daquele item
   - histórico completo de movimentações daquela pessoa

Nenhuma tabela nova foi criada. A lógica continua calculando tudo pelo histórico das movimentações.
