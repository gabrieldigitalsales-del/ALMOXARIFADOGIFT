# Ajuste de notificação e salvar com Enter

Alterações aplicadas:

- Ao clicar na notificação de estoque baixo/em falta, o sistema filtra e destaca o item no estoque.
- Não abre mais automaticamente o modal de detalhes do item.
- Corrigido o comportamento de ficar reabrindo/piscando os detalhes.
- No cadastro de item do estoque, agora pressionar Enter salva o item.
