# Devolução direta por colaborador

Na aba Colaboradores, dentro da tela interna de cada pessoa, cada ferramenta agora possui botão Devolver.

Fluxo:
- abre o colaborador
- clica em Devolver na ferramenta
- confirma a quantidade
- o sistema registra automaticamente uma movimentação do tipo devolução
- o estoque é atualizado
- a quantidade é reduzida/removida do card da pessoa

Observação:
A devolução usa o histórico de movimentações e o item do estoque pelo nome da ferramenta.
