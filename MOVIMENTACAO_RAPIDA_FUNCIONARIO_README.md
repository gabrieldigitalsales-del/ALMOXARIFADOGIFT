# Movimentação rápida para funcionário

A tela de Movimentações agora muda conforme o perfil:

## Administrador
Continua vendo a tela completa de movimentações, com OP e visão administrativa.

## Funcionário do almoxarifado
Vê uma tela simplificada para uso diário no balcão:

- botões grandes de Entrada, Saída, Voltou para o estoque e Perda
- busca rápida por nome, código ou categoria
- seleção visual do item
- quantidade com botões + e -
- motivo com opções prontas
- resumo do estoque do item selecionado
- histórico das movimentações feitas no dia

A tela não mostra custos, preços, valores, OP, orçamento, frete ou garantia.
